# Evaluation

Live eval-набор для измерения поведения агента на реальном DeepSeek. Он отделён от production-кода и запускается только вручную.

## Запуск

```bash
npm run eval
npm run eval -- --task fix-failing-test
```

Каждая задача выполняется в собственной временной директории, имеет ограничение по времени и числу вызовов модели. Отчёты сохраняются в `research/evaluation/results/`, который игнорируется Git.

## Покрываемые сценарии

- чтение одного и нескольких файлов;
- прямой ответ без инструментов;
- создание и проверка файла;
- точное изменение одного или двух файлов;
- выполнение bash-команды;
- восстановление после ошибки инструмента;
- исправление падающего теста;
- продолжение JSONL-сессии.

> Eval выполняет реальные платные запросы DeepSeek. Отчёты содержат ответы модели и результаты инструментов; не публикуйте их без проверки.
