# Minimal AI Agent

Минимальное событийное ядро coding-агента на TypeScript с DeepSeek в качестве модели.

## Установка

```bash
npm install
```

## Инструменты

В режиме DeepSeek агент получает четыре базовых инструмента по образцу pi:

- `read(path, offset?, limit?)` — читает текстовый файл по относительному или абсолютному пути; результат ограничен 2 000 строками или 50 КиБ.
- `bash(command, timeout?)` — запускает команду в рабочей директории и возвращает stdout/stderr.
- `edit(path, edits)` — выполняет точные уникальные замены `oldText` → `newText` в исходном файле.
- `write(path, content)` — создаёт или полностью перезаписывает файл, создавая родительские директории.

`echo` существует только в тестах ядра.

## Сессии и трассировки

Каждый запуск создаёт JSONL-журнал в `.agent/sessions/<session-id>.jsonl`. В нём сохраняются задачи, обращения к модели, решения модели и результаты инструментов. Директория игнорируется Git.

Продолжить сессию можно так:

```bash
npm run dev -- --resume <session-id> "теперь запусти тесты"
```

> Файл сессии может содержать результаты `read` и `bash`, включая случайно раскрытые секреты. Он предназначен только для локального исследования.

## Запуск

Запишите временный ключ в локальный файл `.env.local`:

```dotenv
DEEPSEEK_API_KEY=ваш_временный_ключ
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

Файл загружается автоматически при `npm run dev` и `npm start` и игнорируется Git.

### Системный промпт

Перед первой модельной генерацией агент загружает и объединяет Markdown-файлы в таком порядке:

1. `prompts/SYSTEM.md` — базовые инструкции агента;
2. `~/.minimal-ai-agent/SYSTEM.md` — глобальные инструкции пользователя, если файл существует;
3. `.agent/SYSTEM.md` в рабочей директории — инструкции конкретного проекта, если файл существует;
4. пути из `AGENT_SYSTEM_PROMPT_PATHS` через `;` на Windows или `:` на Unix.

Поздние файлы дополняют ранние. Промпт применяется ко всем обращениям модели в текущем процессе, поэтому после изменения файла перезапустите REPL.

> В экспериментальном режиме инструменты не ограничены рабочей директорией и могут прочитать `.env.local`. `bash` выполняет произвольные команды с правами текущего пользователя. Не используйте ключ с важным балансом и не запускайте агент в каталоге с чувствительными данными.

Интерактивный диалог с потоковым выводом:

```bash
npm run dev
```

Команды REPL: `/new`, `/session`, `/exit`. Вывод разделён цветными блоками; для отключения ANSI-стилей задайте `NO_COLOR=1`.

Одноразовая задача:

```bash
npm run dev -- "Прочитай package.json и README.md, затем объясни устройство проекта"
```

Продолжение сохранённой сессии в REPL:

```bash
npm run dev -- --resume <session-id>
```
